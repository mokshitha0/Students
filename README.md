# Students Management SQL

## 📌 Project Overview

This project contains SQL queries for a Students Management System using MySQL.

The project focuses on analyzing student marks based on departments and demonstrates the use of aggregate functions, grouping, filtering, sorting, and limiting results.

## 🗂️ Students Table

The `Students` table contains the following columns:

- `student_id` – Student ID
- `student_name` – Student Name
- `department` – Student Department
- `marks` – Student Marks

## 📝 SQL Concepts Covered

- SELECT
- WHERE
- GROUP BY
- HAVING
- ORDER BY
- LIMIT
- COUNT()
- AVG()
- SUM()
- MAX()
- MIN()

36. Departments sorted by average marks
37. Top 3 departments based on average marks
38. Departments with average marks between 70 and 90
39. Total marks scored in each department
40. Departments sorted by total number of students
41. Lowest mark in each department
42. Departments where the highest mark is greater than 90
43. Number of students scoring above 80 in each department
